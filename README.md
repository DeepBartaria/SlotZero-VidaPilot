# MedaVida Hackathon - Frontend Template

Modern, high-performance React frontend template built with Next.js 16, React 19, Framer Motion, Three.js WebGL, and Tailwind CSS v4.

## Features Included

- **Apple-Style Welcome Overlay**: Multi-language animated greeting (`Hello`, `Namaste`, `Hola`, `Bonjour`, `Ciao`, `こんにちは`, `안녕하세요`, `你好`) with smooth spring reveal.
- **3D Starfield Background**: Interactive Three.js WebGL starfield with slow continuous drift and cursor parallax steering.
- **Modern Landing Page**:
  - Translucent glassmorphism floating navbar
  - Hero header with high-contrast typography and subtle text shadows
  - Scroll-driven horizontal card reveal section
  - Social proof marquee
  - Feature & module cards with micro-animations
  - Responsive collapsible FAQ accordion
  - High-conversion gradient CTA banner and modern footer
- **Design System**: Full Tailwind CSS v4 token scale, typography, and reusable UI primitives.

## Quick Start

```bash
# Run the development server
bun run dev
# or: npm run dev

# Open in browser
open http://localhost:3000
```

## Production Build

```bash
bun run build
# or: npm run build
```
